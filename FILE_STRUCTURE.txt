Docker Compose Services
=======================

1. postgres          - PostgreSQL 16 with gridflow & spiffworkflow databases
2. redis             - Redis 7 with persistence
3. spiff-arena       - sartography/spiff-arena:latest (BPMN engine)
4. api-gateway       - Custom FastAPI service
5. ai-service        - Custom PyTorch AI service
6. client-web        - Custom Next.js application

All services connected via gridflow-network bridge network.

Authentication Placeholders
===========================

eID Authentication:
- POST /auth/eid/initiate       - Start eID flow
- POST /auth/eid/callback       - Handle provider callback

WebAuthn (Passkey) Authentication:
- POST /auth/webauthn/register/begin      - Start registration
- POST /auth/webauthn/register/complete   - Complete registration
- POST /auth/webauthn/authenticate/begin  - Start authentication
- POST /auth/webauthn/authenticate/complete - Complete authentication

Database tables ready for WebAuthn credential storage.

Quick Commands
==============

Setup:
  ./setup.sh              # Initialize everything
  ./validate.sh           # Validate structure

Make Commands:
  make setup              # Run setup script
  make up                 # Start all services
  make down               # Stop all services
  make logs               # View logs
  make ps                 # Service status
  make clean              # Remove all data
  make api                # Start API Gateway only
  make ai                 # Start AI Service only
  make web                # Start Client Web only

Docker Compose:
  docker-compose up -d    # Start all services
  docker-compose logs -f  # Follow logs
  docker-compose ps       # Service status
  docker-compose down -v  # Stop and remove volumes
